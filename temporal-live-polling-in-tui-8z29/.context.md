# Goal
Poll Temporal for live workflow state on startup and every 30 seconds. Apply ShaveState updates to repos so the sidebar reflects live workflow progress.

# Files
- `tui/model.go` — add temporalAllMsg, queryTemporalCmd(), terminalShaveState(), update Init() and pollTickMsg handler

# New types
```go
type temporalAllMsg struct {
    states      []*temporal.WorkflowState
    shaveStates []*temporal.ShaveState
}
```

# Behaviour

`queryTemporalCmd() tea.Cmd`:
- Collects all repo WFIDs
- When engine==nil: returns nil (tests pass without live Temporal)
- When engine!=nil: calls engine.QueryAll, returns temporalAllMsg

`Init()` returns `tea.Batch(queryTemporalCmd(), tea.Tick(pollInterval, ...))` so the first query fires immediately on startup.

`pollTickMsg` handler fires both queryTemporalCmd() and next tick. When showHistory==true, also fires fetchHistoryCmd(historyWfID).

`temporalAllMsg` handler:
- For each ShaveState, find the repo that contains a yak with matching YakName
- Set repo.ShaveState = shaveState
- For terminal workflow states (Status != 0/1), call terminalShaveState() to synthesize a ShaveState
- Calls updateSidebar() after applying

`terminalShaveState(yakName string, code int32) *temporal.ShaveState`:
- code 2 (COMPLETED) → Phase "done"
- code 3 (FAILED) → Phase "failed"
- code 4 (CANCELED) → Phase "cancelled"

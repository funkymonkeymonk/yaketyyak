# Goal
Replace the always-visible right sidebar with a modal popup overlay that appears
when the user presses `enter` on a yak. The popup covers a centered portion of
the screen and shows full yak detail (name, state, ID, PR, full context markdown).
Dismisses with `esc` or `q`.

This frees up horizontal space in the main tree view (which currently loses ~50%
width to a permanent sidebar) and makes detail feel intentional rather than ambient.

# Acceptance Criteria
- [ ] Pressing `enter` on a yak opens a centered overlay rendering full detail
- [ ] Overlay is visually distinct (border, shadow/dimmed background)
- [ ] Overlay renders full `.context.md` content with scrolling if needed
- [ ] `esc` or `q` dismisses the overlay and returns focus to the tree
- [ ] The tree pane expands to full width when no overlay is open
- [ ] Help bar updates to show overlay-mode key hints when overlay is open

# Files
- tui/model.go (add overlay open/close state, handle keys)
- tui/overlay.go (new file: overlay rendering component)
- tui/sidebar.go (remove or repurpose — sidebar content moves into overlay)
- tui/context.go (remove sidebar width allocation when sidebar unused)
- tui/keys.go (ensure Close/Dismiss binding exists)

# Notes
- The confirm dialog (`showConfirm`) is a precedent for overlay rendering — use
  the same `lipgloss.Place` centering approach
- `sidePanel sidebarModel` can be kept for data but its `View()` output redirected
  into the overlay rather than rendered inline

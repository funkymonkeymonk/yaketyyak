# WorkflowEngine interface

```go
type WorkflowEngine interface {
    StartShave(ctx context.Context, yakName, repoURL string, llm LLMConfig) error
    QueryAll(ctx context.Context, wfIDs []string) ([]*WorkflowState, []*ShaveState, error)
    GetHistory(ctx context.Context, wfID string) ([]*historypb.HistoryEvent, string, error)
    Signal(ctx context.Context, wfID, signal string) error
}
```

TemporalEngine is the production implementation using go.temporal.io/sdk. The TUI stores a WorkflowEngine interface value — nil in tests, TemporalEngine in production. All TUI calls guard with `if m.engine != nil`.

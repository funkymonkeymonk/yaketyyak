# Goal
Enforce the Go↔TypeScript type contract for shared Temporal payload types at test/compile time, with no codegen, no new tools, and no pre-build steps.

# Approach
Single canonical JSON fixture checked into the repo. Go test unmarshals it and asserts all required fields are populated. TypeScript compile-time assignment asserts the fixture satisfies the interface types.

# Files
- `proto/yak_types.json` — canonical fixture with one concrete example of each shared type: WorkflowConfig, PiConfig, YakWorkflowState
- `temporal/contract_test.go` — Go test: reads fixture, unmarshals into Go structs, asserts no required string fields are empty
- `worker/src/types.ts` — add two compile-time assignment lines: `const _: WorkflowConfig = fixture.workflowConfig` etc. (using JSON import assertion); tsc catches drift at build time

# Acceptance Criteria
- [ ] `proto/yak_types.json` exists with a complete concrete example of all shared types
- [ ] `go test ./temporal/...` fails if a field is renamed in `temporal/types.go` without updating the fixture
- [ ] `npm run build` (tsc) fails if a field is removed or renamed in `worker/src/types.ts` without updating the fixture
- [ ] No new packages, tools, or codegen steps required

# Dependencies
None — can be implemented independently of other yaks in this group.

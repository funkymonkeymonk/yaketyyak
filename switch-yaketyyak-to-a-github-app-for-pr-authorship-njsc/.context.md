# Switch yaketyyak to a GitHub App for PR authorship

## Status: @needs-human

A human must complete the setup steps below before this yak can be shaved.

## Why

Currently yaketyyak uses a personal PAT (`op://Employee/Yaketyyak/Github Token`).
PRs show up as created by the PAT owner's personal account. A GitHub App gives
yaketyyak its own identity — PRs clearly show "opened by yaketyyak[bot]", making
it obvious which PRs are autonomous vs human-created.

The code change is minimal — only the Octokit instantiation changes.

## Human setup steps

### 1. Create the GitHub App

Go to: https://github.com/organizations/funkymonkeymonk/settings/apps/new
(or personal: https://github.com/settings/apps/new)

Settings:
- **App name**: `yaketyyak`
- **Homepage URL**: `https://github.com/funkymonkeymonk/yaketyyak`
- **Webhooks**: uncheck "Active" (not needed)
- **Permissions** (Repository):
  - Contents: Read & write
  - Pull requests: Read & write
  - Metadata: Read-only
- **Where can this app be installed**: Only on this account

### 2. Generate a private key

After creating the app:
- Note the **App ID** (shown on the app's settings page)
- Click **Generate a private key** — downloads a `.pem` file

### 3. Install the app on the repo

- Go to the app's settings → **Install App**
- Install on `funkymonkeymonk/yaketyyak`
- Note the **Installation ID** from the URL:
  `https://github.com/organizations/funkymonkeymonk/settings/installations/<INSTALLATION_ID>`

### 4. Store in 1Password

Add these fields to the `Yaketyyak` item in the `Employee` vault:

| Field name | Value |
|---|---|
| `GITHUB_APP_ID` | The numeric App ID |
| `GITHUB_APP_PRIVATE_KEY` | Full contents of the `.pem` file |
| `GITHUB_APP_INSTALLATION_ID` | The numeric Installation ID |

Then remove `Github Token` from the item (or keep for fallback during transition).

### 5. Tag this yak @g2g

Once 1Password is updated, tag this yak `@g2g` and the shave workflow will
implement the code change.

## Code change (for the agent)

### Add dependency

```bash
cd worker && npm install @octokit/auth-app
```

### Update `worker/src/activities.ts`

Replace the Octokit instantiation in `CreateDraftPR` and `WatchPRMerged`:

```typescript
// Before (PAT)
import { Octokit } from "@octokit/rest";
const octokit = new Octokit({ auth: process.env.GITHUB_TOKEN });

// After (GitHub App)
import { Octokit } from "@octokit/rest";
import { createAppAuth } from "@octokit/auth-app";

const octokit = new Octokit({
  authStrategy: createAppAuth,
  auth: {
    appId: process.env.GITHUB_APP_ID,
    privateKey: process.env.GITHUB_APP_PRIVATE_KEY,
    installationId: process.env.GITHUB_APP_INSTALLATION_ID,
  },
});
```

### Update `.env.op`

Replace:
```
GITHUB_TOKEN=op://Employee/Yaketyyak/Github Token
```

With:
```
GITHUB_APP_ID=op://Employee/Yaketyyak/GITHUB_APP_ID
GITHUB_APP_PRIVATE_KEY=op://Employee/Yaketyyak/GITHUB_APP_PRIVATE_KEY
GITHUB_APP_INSTALLATION_ID=op://Employee/Yaketyyak/GITHUB_APP_INSTALLATION_ID
```

## Acceptance criteria

- PRs created by the workflow show `yaketyyak[bot]` as author on GitHub
- `GITHUB_TOKEN` env var is no longer needed
- All existing PR create/watch/merge behaviour is unchanged
- The old PAT field in 1Password can be removed

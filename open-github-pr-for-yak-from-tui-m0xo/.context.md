# Goal
Allow the user to open the GitHub PR associated with a yak directly from the TUI
using a key binding (e.g. `o`). This uses the `.pr` file URL already stored in
`YakLine.PRURL` and opens it in the system browser.

# Acceptance Criteria
- [ ] Pressing `o` on a yak that has a `.pr` URL opens it in the system browser
- [ ] If no PR URL is set, pressing `o` shows a brief status message "no PR for this yak"
- [ ] The browser open is non-blocking (fire-and-forget `open`/`xdg-open` subprocess)
- [ ] Key hint `o:open PR` is shown in the help bar when a yak with a PR is selected
- [ ] Works on macOS (`open`) and Linux (`xdg-open`)

# Files
- tui/keys.go (add OpenPR key binding)
- tui/model.go (handle OpenPR in handleKey, run open/xdg-open subprocess)
- tui/footer.go (add hint to help text)

# Notes
- The PR tab already has `[o] Open PR in browser` in `showPRDetail` sidebar —
  this extends that capability to the main yak tree.
- Use `exec.Command("open", url)` on darwin, `exec.Command("xdg-open", url)` on linux.
  Can detect via `runtime.GOOS`.
- The `open` call should be wrapped in a `tea.Cmd` (fire-and-forget, discard result
  or return a `statusMsg` on completion).

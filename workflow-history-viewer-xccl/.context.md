# Goal
Full-screen history view triggered by `h` key. Shows Temporal workflow event log for the selected workflow, with sort toggle and live refresh on poll tick.

# Files
- `tui/model.go` — add showHistory/historyWfID/historyStatus/historyLines/historySpans/historyTimelineReverse fields; add showWorkflowHistory(), historyTargetWFID(), fetchHistoryCmd(), historyLoadedMsg handler; update View(), handleKey(), pollTickMsg handler
- `tui/keys.go` — add History (h) and ToggleSort (t) key bindings

# New fields on Model
```go
showHistory            bool
historyWfID            string
historyStatus          string
historyLines           []string
historySpans           []activitySpan
historyTimelineReverse bool
```

# New message type
```go
type historyLoadedMsg struct {
    lines  []string
    spans  []activitySpan
    status string
}
```

# Behaviour

`historyTargetWFID()`:
- If current selection is a yak and its repo has a ShaveState with a non-terminal phase → return temporal.ShaveWorkflowID(yak.Name)
- Otherwise → return repo.WFID

`showWorkflowHistory()`:
- Sets showHistory=true, historyWfID from historyTargetWFID(), historyLines=["Loading..."]
- Returns (model, fetchHistoryCmd(wfID))

`fetchHistoryCmd(wfID string) tea.Cmd`:
- When engine==nil: returns cmd sending historyLoadedMsg{lines:["(no live engine — start devenv up)"], status:""}
- When engine!=nil: calls engine.GetHistory, formats events into lines, extracts spans, returns historyLoadedMsg

History view rendering (when showHistory==true, replaces normal content):
- Header: "Workflow History  <wfID>  [STATUS]   t:toggle-sort  esc:close"
- Separator line
- Event list (reversed when historyTimelineReverse==false, i.e. newest first by default)
- Timeline section with formatSpanBar rows (from activity timeline spans yak)
- Total height must equal m.height (same constraint as normal view)

Key handling when showHistory:
- esc → showHistory=false
- t → toggle historyTimelineReverse, re-render

`h` key when NOT in history → showWorkflowHistory()

## Goal

Add a new \`InitWorkspaceForResume\` activity to \`worker/src/activities.ts\` that clones the repo and checks out the existing shave branch (rather than creating a new one). This is needed so subsequent \`PushFeedbackCommit\` calls have a local workspace to operate on.

## Prerequisites

- "add resume fields to WorkflowConfig and types" must be done

## Acceptance Criteria

- [ ] \`InitWorkspaceForResume(repoUrl: string, yakName: string): Promise<string>\` is exported from \`activities.ts\`
- [ ] It clones the repo into the same \`.workspaces/<workspaceName>\` path as \`InitWorkspace\`
- [ ] It checks out the existing \`shave/<slug>\` branch (not creating a new one: \`git checkout <branch>\` not \`git checkout -b\`)
- [ ] It sets the git identity (email + name) the same way \`InitWorkspace\` does
- [ ] If the branch does not exist on origin, it returns a clear error
- [ ] \`npm run build\` passes

## Files

- \`worker/src/activities.ts\` — add \`InitWorkspaceForResume\` export alongside \`InitWorkspace\`

## Notes

The workspace slug and branch derivation logic should be identical to \`InitWorkspace\` — extract a shared helper \`workspaceSlug(yakName)\` if not already done.

# Goal
Extract activity spans from Temporal history events and render them as a text-based timeline (mini Gantt) in the history view.

# Files
- `tui/history.go` — new file containing: activitySpan, extractSpans(), formatSpanBar(), formatEventDetail(), durLabel(), firstLine()

# Types
```go
type activitySpan struct {
    name     string
    offset   time.Duration  // time from workflow start to activity scheduled
    duration time.Duration  // scheduled to completed/failed
    status   string         // "completed", "failed", "running"
    errMsg   string
}
```

# Functions

`extractSpans(events []*historypb.HistoryEvent) []activitySpan`:
- Walks events in order
- Pairs ActivityTaskScheduled → ActivityTaskCompleted / ActivityTaskFailed
- Returns empty slice if no activity events (not nil)

`formatSpanBar(s activitySpan, width int, total time.Duration) string`:
- Renders one timeline row: `Name    ░░░▓▓▓▓▓░ ✓ 500ms` (or ✗ for failed)
- Bar width proportional to offset and duration within total
- Appends errMsg (first line only) for failed spans
- `✓` for completed, `✗` for failed, `→` for running

`formatEventDetail(ev *historypb.HistoryEvent, attrs interface{}) string`:
- Returns human-readable detail string for known event attribute types
- Returns "" for unknown/nil attrs (satisfies TestFormatEventDetail_NoAttributes)

`durLabel(d time.Duration) string`:
- d < 1s → "500ms" (integer ms)
- d < 60s → "2.5s" (one decimal)
- d >= 60s → "2m5s"

`firstLine(s string) string`:
- Returns text before first \n or \r
- Returns full string if no newline

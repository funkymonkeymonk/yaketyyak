# Problem

Almost all docs describe aspirational/phantom workflows (BarberWorkflow,
ShaveWorkflow, CI signals, 5 CLI subcommands) that do not exist in code.
The only real workflow is YakWorkflow invoked via `yyx shave`. Agents and
humans reading the docs will be confused or misled into using wrong commands
and expecting features that are not implemented.

## Specific inaccuracies

- `yyx start` is documented everywhere — the real command is `yyx shave`
- 5 phantom signals documented (ci_signal, g2g_signal, pr_feedback, pause, resume) — only `wont-do` exists
- 4 selectable agents documented — only Pi via LiteLLM is implemented
- BarberWorkflow and ShaveWorkflow documented — only YakWorkflow exists
- `--agent`, `--repo` flags documented — real flags are `--pi-model`, `--pi-tools`, `--pi-skill`
- Real activities (YakClaim, YakRelease, YakMarkDone, WritePRToYak, InitWorkspace,
  CleanupWorkspace, RunAgent, CreateDraftPR, WatchPRMerged) are undocumented
- Real types (PiConfig, YakWorkflowState, PRResult) are undocumented

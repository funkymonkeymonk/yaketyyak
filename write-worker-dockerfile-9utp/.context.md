# Problem
No Dockerfile exists for the TypeScript worker. The container must bundle the
compiled worker, install system dependencies (`git`, `yx` v0.2.0), and be
configurable via `WORKER_ROLE` and `TEMPORAL_HOST_PORT` at runtime.

# Acceptance Criteria
- [ ] `worker/Dockerfile` exists with a two-stage build:
  - Stage 1 (`builder`): `node:22-alpine` — `npm ci` + `tsc`
  - Stage 2 (`runner`): `node:22-alpine` — runtime image
- [ ] Runtime image installs: `git`, `curl`, `bash`, `openssh-client`, `ca-certificates` via `apk add`
- [ ] `yx` v0.2.0 binary installed via the official installer script from `https://raw.githubusercontent.com/mattwynne/yaks/main/install.sh` with `YX_VERSION=0.2.0`
- [ ] `dist/` and `node_modules/` copied from builder stage
- [ ] `WORKDIR /workspace` set in runner stage
- [ ] `ENV TEMPORAL_HOST_PORT=""` and `ENV WORKER_ROLE="shaver"` declared
- [ ] `CMD ["node", "dist/worker.js"]` as entrypoint
- [ ] Image builds successfully for `linux/amd64` platform
- [ ] `.dockerignore` created at `worker/.dockerignore` excluding `node_modules/`, `dist/`, `.env*`

# Notes
The `yx` installer downloads a linux/amd64 Rust binary. Verify the installer
supports `YX_VERSION` env var (confirmed in v0.2.0 release notes).
The runner stage does NOT need npm or TypeScript — only the compiled `dist/`
and `node_modules/` from the builder.
`openssh-client` is needed for authenticated git push operations.

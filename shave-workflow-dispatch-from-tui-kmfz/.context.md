# Goal
Allow the user to start a shave workflow directly from the yak list with a confirmation step. Implements `shaveYak()`, `doShaveYak()`, and the `s` key binding.

# Files
- `tui/model.go` — add shaveYak(), doShaveYak(), update handleConfirmKey(), update New() signature
- `tui/types.go` — add ShaveState *temporal.ShaveState to Repo struct
- `tui/keys.go` — add Shave key.Binding (s)

# Behaviour

`shaveYak()`:
- Called when user presses `s` on a yak line
- Sets showConfirm=true, confirmMsg="Shave yak: <name>?", confirmAction="shave"
- Returns (model, nil) — no command yet

`doShaveYak()`:
- Called when user confirms with enter and confirmAction=="shave"
- Guards: if selected line is not treeYak, returns (model, nil)
- Sets repos[i].ShaveState = &ShaveState{YakName: name, Phase: "starting"}
- Sets statusMsg to indicate workflow starting
- Returns (model, cmd) where cmd calls engine.StartShave and returns signalMsg
- When engine==nil: cmd immediately returns signalMsg{action:"shave <name>", err:nil}

New() signature: `New(repos []Repo, llm temporal.LLMConfig) Model`
Engine is created internally by New() when Temporal is available, stored as interface.

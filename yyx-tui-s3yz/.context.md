Build a Bubble Tea TUI as a `yyx tui` subcommand. Multi-pane layout with yak tree (left), detail pane (right), and status bar (bottom). Reads .yaks/ from filesystem, queries Temporal for workflow state, allows sending signals (start, pause, resume, g2g-scan, ci). Keyboard-driven (j/k nav, single-key actions). Architecture: tui/ package with yaks.go (data model + filesystem reader), render.go (tree/detail/status rendering), model.go (Bubble Tea model + key bindings). cmd/tui.go for Cobra command registration. Follows Pi philosophy: minimal core, primitives not features, extension-ready for v2.

## Goal

## Acceptance Criteria

- [ ] \`WorkflowConfig\` (TS) gains optional \`resumePrNumber?: number\` field
- [ ] \`WorkflowConfig\` (Go \`temporal/types.go\`) gains matching \`ResumePrNumber int\` JSON field
- [ ] Both types remain backward-compatible (zero value = normal fresh-start behaviour)
- [ ] \`go build ./...\` and \`npm run build\` (or equivalent task) pass with no errors

## Files

- \`worker/src/types.ts\` — add \`resumePrNumber?: number\` to \`WorkflowConfig\`
- \`temporal/types.go\` — add \`ResumePrNumber int \`json:"resumePrNumber,omitempty"\`\` to \`WorkflowConfig\`
